# Hi, I'm Jonas!

I'm studying Applied Computer Science (M.Sc.) at Chemnitz University of Technology, focusing on embedded systems. I'm particularly interested in software engineering, autonomous systems, and the design of reliable, modular software.

Alongside my studies, I work as a student research assistant at the Chair of Computer Engineering. As part of the [**SmartCargoDrone**](https://www.tu-chemnitz.de/informatik/ce/projects/smartcargodrone.php) project, I'm developing a Mission Control System based on ROS 2 and Behavior Trees. In addition to software development, I supervise practical sessions for the Master's course Automotive Software Engineering.

I also work in industrial software development. This includes the development of software interfaces for hardware systems.

## What I work on

- **Autonomous systems:** mission execution, subsystem coordination, and fault handling
- **Software architecture:** modularity, extensibility, and reusable components
- **Embedded and industrial software:** C/C++, C#, Python, and build systems
- **Formal methods:** behavioral specification, model-driven development, and verification

## Projects and academic work

- **Mission Control System for Autonomous Cargo Drones** — Ongoing bachelor's thesis on the design and prototype implementation of a ROS 2-based mission execution and coordination system.
- **[QKD Security Standardization](https://github.com/jlorenz-eng/qkd-security-standardization)** — Comparative analysis of ISO/IEC 23837-1 and ETSI GS QKD 016 based on the Common Criteria.
- **[CLP(FD) vs. CP-SAT](https://github.com/jlorenz-eng/Vergleich-CLP-FD-und-CP-SAT)** — Comparison of constraint-solving approaches, including benchmarks based on N-Queens and the 7-11 problem.
